# @webs/block-example

Bloque de referencia de la plataforma **Webs**. Demuestra el contrato completo
de un bloque: manifiesto (`block.json`), entrada de servidor (Fastify), entrada
de cliente (render en slot), esquema de configuración y hooks de ciclo de vida.

Ver `docs/guides/crear-un-bloque.md` para la guía completa de desarrollo.
