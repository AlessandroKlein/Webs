# OCA

Cotización de envíos con OCA (SOAP Tarifar_Envio_Corporativo).

## Metadatos

| Campo | Valor |
|-------|-------|
| id | `oca` |
| versión | `0.1.0` |
| autor | Webs |
| licencia | MIT |
| categoría | `envios` |
| apiVersion | `1.0.0` |
| repositorio | https://github.com/AlessandroKlein/Webs |

## Proveedores que ofrece

- `shipping`

## Configuración

Opciones: `enabled`, `username`, `password`, `cuit`, `baseUrl`.
