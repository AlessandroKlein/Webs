# Mercado Envíos

Cotización de envíos con Mercado Envíos (/items/{id}/shipping_options).

## Metadatos

| Campo | Valor |
|-------|-------|
| id | `mercadolibre` |
| versión | `0.1.0` |
| autor | Webs |
| licencia | MIT |
| categoría | `envios` |
| apiVersion | `1.0.0` |
| repositorio | https://github.com/AlessandroKlein/Webs |

## Proveedores que ofrece

- `shipping`

## Configuración

Opciones: `enabled`, `accessToken`, `itemId`, `baseUrl`.
