# Correo Argentino

Cotización de envíos con Correo Argentino MiCorreo (Basic auth → JWT → /rates).

## Metadatos

| Campo | Valor |
|-------|-------|
| id | `correo` |
| versión | `0.1.0` |
| autor | Webs |
| licencia | MIT |
| categoría | `envios` |
| apiVersion | `1.0.0` |
| repositorio | https://github.com/AlessandroKlein/Webs |

## Proveedores que ofrece

- `shipping`

## Configuración

Opciones: `enabled`, `userToken`, `passwordToken`, `customerId`, `originPostalCode`, `baseUrl`.
