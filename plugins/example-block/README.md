# @webs/block-example

Plugin de referencia de la plataforma **Webs**. Demuestra el contrato completo
de un plugin: manifiesto (`plugin.json`), entrada de servidor (Fastify), entrada
de cliente (render en slot), esquema de configuración y hooks de ciclo de vida.

Ver `docs/guides/crear-un-bloque.md` para la guía completa de desarrollo.
