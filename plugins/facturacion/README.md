# Facturación

Generación de facturas con emisión fiscal (CAE).

## Metadatos

| Campo | Valor |
|-------|-------|
| id | `facturacion` |
| versión | `0.1.0` |
| autor | Webs |
| licencia | MIT |
| categoría | `negocio` |
| apiVersion | `1.0.0` |
| repositorio | https://github.com/AlessandroKlein/Webs |
